# Python - Estruturas de Repetição e Decisão

## 📖 Objetivo

Este repositório reúne exercícios acadêmicos desenvolvidos em Python com foco na utilização de estruturas de decisão e repetição para resolução de problemas computacionais.

## 📂 Conteúdo

O repositório contém exercícios sobre:

- Estruturas condicionais (`if`, `elif` e `else`);
- Estruturas de repetição (`for` e `while`);
- Desenvolvimento da lógica de programação;
- Entrada e saída de dados.

## 💻 Tecnologias

- Python 3

## ▶️ Como executar

1. Instale o Python 3 em seu computador.
2. Clone este repositório ou faça o download dos arquivos.
3. Execute o arquivo desejado pelo terminal:

```bash
python nome_do_arquivo.py
```
